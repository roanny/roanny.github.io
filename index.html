AI agent for Looker developers on BigQuery

Coabana · 2025–present

An agent that lives inside Looker as an extension. From a request in plain language it produces a complete LookML project — views, explores, models, Looks and dashboards — validating every step against Looker and BigQuery, diagnoses existing dashboards and answers questions over the semantic layer, acting with the permissions of the user who asks. A Python agent on Google ADK on Cloud Run, the MCP server of the next card, and a React extension served by Looker; in production at a reference installation.

In production

MCP server for the Looker API

Coabana · 2025–present

A Model Context Protocol server for the Looker API, open to any MCP client — an agent, Claude, Gemini or a developer's IDE — built for production rather than for a demo. Ten tool groups, from queries and explores to LookML, git and administration; per-user sessions that keep each developer's dev mode where they left it; the same tool names and capabilities as Google's MCP Toolbox for Looker, with folders, administration and content updates and deletes on top; and gates that refuse the irreversible operations unless they are explicitly enabled. It is the Looker arm of the agent above and runs beside it on Cloud Run.
